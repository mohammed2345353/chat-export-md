# Contributing

Issues and pull requests are welcome.

1. Fork and clone the repo.
2. `pip install -e .`
3. Run the tests: `python -m unittest discover -s tests -v`
4. Keep the project dependency-free and add a test for every change.

Found a new error format, log format or edge case? Open an issue with a
**redacted** sample — never paste API keys or private conversations.
